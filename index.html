Mathematical details · Why do the two correlations behave differently?

White Noise control. Choose independent Rademacher signs ξk ∈ {−1,+1}. For each k, let Ik ∼ Bernoulli(ε) and an independent copy ξ̃k. Write ξkε = (1−Ik)ξk + Ikξ̃k. The two partial sums use the identical time grid Δt = δ² and the same N as the Brownian Web simulation.

Bδ(t) = δ ∑0≤k<t/δ² ξk  ;  Bδ,ε(t) = δ ∑0≤k<t/δ² ξkε Cov(Bδ(TN), Bδ,ε(TN)) = (1−ε)Nδ²  ;  Corr = 1−ε.

Brownian Web approximation. A path follows an independent sign attached to its current space–time lattice site: Xn+1 = Xn + σ(Xn,n). Two paths in the same environment coalesce when they meet. The corresponding original/resampled paths can meet again after separating, so their per-step correlations depend on their meeting probability.

Corr(δXN, δXNε) = (1−ε)/N × ∑n=0N−1 P(Xn = Xnε).

Both endpoint correlations are theoretical finite-step quantities. The Brownian Web value is evaluated by numerical quadrature of the exact meeting-probability expression, not estimated from the displayed paths. For fixed ε > 0 as δ → 0, this single-path Brownian Web correlation tends to zero, whereas the White Noise control stays at 1−ε. The full black-noise theorem concerns the associated interval-factor noise, not just this one observable.

01 · Coalescing walks and diffusive scaling

Xn+1 = Xn + σ(Xn,n)  →  (δXn, δ²n)

The σz are independent symmetric ±1 signs on the even space–time lattice. Each walk follows its fixed arrow field; paths that meet subsequently agree. Only a finite skeleton is drawn, not every path of the continuum Brownian Web.

02 · Independent resampling coupling

σεz = (1 − Iz)σz + Izσ̃z

Iz ∼ Bernoulli(ε); σ̃z is an independent fair sign. Each site has a fixed random threshold, so varying ε adds or removes resampling events without redrawing the original field. The same coupling rule is used for White Noise.

Definition · How does this lattice system approximate the Brownian Web?

The Brownian Web is a random compact family of continuous coalescing Brownian paths. In its standard characterization: (i) almost surely, each deterministic space–time point has a unique outgoing path; (ii) paths from any finite deterministic collection of starting points are distributed as coalescing standard Brownian motions; (iii) all paths are the closure of paths starting from a fixed deterministic countable dense set. Under the diffusive map (x,n) ↦ (δx,δ²n), the full family of parity-lattice coalescing walks converges in distribution in the appropriate path-space topology. This visualization renders a finite selected skeleton of that lattice approximation.

Suggested experiment: Hold ε = 0.025 and decrease δ from 0.02000 to 0.00375. Compare the White Noise control's constant correlation 1−ε with the decreasing single-path Brownian Web correlation. The colored paths are single realizations; the correlations above are theoretical quantities. Dense-grid arrow counts are explicitly labeled as sample-based estimates.
